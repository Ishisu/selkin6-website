# Selkin6 Website — Modernized

A responsive HTML/CSS refresh of the original `Test1.html` page.

## What's included
- Semantic HTML5 structure
- Responsive layouts for desktop, tablet and mobile
- Modern typography, spacing and visual styling
- Accessible navigation and skip link
- Reduced-motion support
- No framework or build tools required

## Run locally
Open `index.html` in any modern web browser.

## Customize before publishing
The original ZIP contained only `Test1.html`. It referenced an `images/` directory, but the image files were not included. Because the original visual assets and page content were unavailable, this refresh uses editable placeholder copy and CSS artwork.

Before publishing:
1. Replace the sample text with the real Selkin6 content.
2. Replace `hello@example.com` with the correct contact email.
3. Add original photos, logos or other assets to `assets/` and update the HTML as needed.
4. Update the page title and meta description if the website has a specific purpose.

## Technologies
- HTML5
- CSS3
- Google Fonts (DM Sans and Manrope; falls back to system fonts)
